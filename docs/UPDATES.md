# 更新検知の設定

非公開リポジトリはログインなしでAPIを読めないため、Macごとに更新確認用のトークンを設定します。
ブラウザでGitHubにログインしていても、アプリへの認証は自動共有されません。

1. アプリを右クリックして設定を開く。
2. 「GitHubでトークンを作成」を開く。
3. Fine-grained personal access tokenを作り、Repository accessは **Only select repositories → codex-barだけ** を選択。
4. Repository permissionsの **Contents → Read-only** を設定。書き込み権限は不要。期限は自分の運用に合わせて指定。
5. 生成されたトークンを **アプリのSecureField** に貼り、「保存して確認」。チャット・ソース・Issueには貼り付けない。
6. 「更新を自動で確認」をオンにする。新規保存時には自動でオンになります。
7. 「更新通知を許可…」でmacOSの通知を許可。

トークンはこのMacのキーチェーンへ保存し、別のMacへ移行・同梱しません。
削除すると更新確認を止めます。GitHub側での失効はGitHubのトークン設定から行います。

自動確認は起動中に1日1回。アプリが終了・スリープ中なら、その間の確認は行いません。
公開済みの通常リリースだけを比較し、ドラフト・プレリリースや不明なバージョン文字列は更新扱いにしません。
同じバージョンの通知は1回に抑えます。

通知をクリックするか、設定の「新しいバージョンを開く」からGitHubの配布ページへ進みます。
GitHubにログインしてZIPをダウンロードし、Codex barを終了してアプリ全体を置き換えてください。
更新用トークンを設定しなくても「GitHubの配布ページ」から手動で最新版を確認できます。

初回リリース公開前は「公開済みリリースがないか、このトークンに閲覧権限がありません」と表示されます。
トークンが期限切れ・権限不足のときはエラーを表示しますが、使用量ウィジェットの取得は継続します。
