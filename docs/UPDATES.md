# 更新確認と通知（1.7.0以降）

公開GitHub Releasesから最新版を確認します。GitHubへのログインも、読み取り用トークンの作成も不要です。
Codexの使用量を取得するためのChatGPTログインは、引き続き各Macの公式Codex CLIで必要です。

1. ウィジェットを右クリックして設定を開く。
2. 「アップデート」の「更新を自動で確認」をオンにする。新規インストールでは初期状態がオンです。
3. 「更新通知を許可…」からmacOSの通知を許可する。
4. 「更新を確認」で、いつでも手動確認できる。

自動確認は起動中に1日1回。終了・スリープ中は確認しません。
既存のオン／オフ設定を引き継ぐため、以前オフにした場合は設定画面でオンにしてください。
通常の公開済みリリースだけを比較し、ドラフト・プレリリースや不明なバージョン文字列は更新扱いにしません。
同じバージョンの自動通知は1回に抑えます。ネット接続エラーやGitHubのアクセス制限は画面に表示します。
更新確認が失敗しても、使用量の取得は継続します。

通知をクリックするか、「新しいバージョンを開く」から配布ページへ進みます。
ZIPをダウンロード・展開し、Codex barを終了してアプリ全体を置き換えてください。インストールは手動です。

## 1.6.0からの移行

1.6.0は非公開GitHub用に作成したため、トークンなしでは自動更新を検知しません。
最初の1回は [最新版の配布ページ](https://github.com/piyoharu97/codex-bar/releases/latest) から1.7.0以降を手動でインストールしてください。
1.7.0以降では、旧版のGitHubトークンを読み出しません。保存済みアイテムは勝手に削除しません。
不要ならmacOSの「キーチェーンアクセス」でサービス名「Codex bar GitHub Updates」の項目を削除できます。
GitHub側でトークンを失効させる場合は、GitHubのPersonal access tokens設定から行ってください。
